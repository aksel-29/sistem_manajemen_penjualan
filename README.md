# sistem_manajemen_penjualan
Axel Shop adalah sistem manajemen penjualan yang fungsional, ringan, dan telah diamankan dengan baik untuk mencatat serta memantau profit dari tiga lini usaha (akun game, top up, dan kelinci). Sangat cocok untuk pemilik usaha pribadi yang ingin mencatat penjualan dan menghitung keuntungan secara terpusat dari HP atau laptop.
